# Playbook Plugin

코딩 전 사고를 돕는 요청 템플릿 모음입니다. 여러 프로젝트에서 반복적으로 사용하는 요청 패턴을 하나의 플러그인으로 통합하여 어디서든 재사용할 수 있게 합니다.

## 기능 요약

| 구분 | 이름 | 설명 |
|------|------|------|
| Command | `/playbook:architecture` | 코드베이스를 탐색하고 아키텍처를 ASCII 다이어그램으로 시각화 |
| Command | `/playbook:design` | 아이디어 단계부터 설계 완료까지 단계별 논의를 이끄는 퍼실리테이션 |

## 설치

```bash
/plugin install playbook@jiseonlee-plugins
```

---

## Commands

### `/playbook:architecture [관심사]`

코드베이스를 깊이 탐색한 뒤, 프로젝트의 아키텍처를 ASCII로 단 하나의 그림으로 시각화합니다.

**사용법:**
```bash
/playbook:architecture                    # 프로젝트 전체 아키텍처
/playbook:architecture 인증 시스템         # 특정 관심사에 집중
```

**동작:**
1. 패키지 구조, 핵심 클래스, 진입점, 패턴을 탐색
2. 핵심 패턴을 중심으로 계층과 컴포넌트 연결을 ASCII로 시각화
3. 보충 테이블로 각 컴포넌트의 역할을 설명

---

### `/playbook:design <아이디어>`

아이디어를 구체적인 설계로 발전시키는 퍼실리테이션을 진행합니다.

**사용법:**
```bash
/playbook:design 사용자 알림 시스템
```

**동작:**
1. **Phase 1: 문제 정의** -- 핵심 문제, 대상, 배경 파악
2. **Phase 2: 범위 결정** -- MVP와 확장 기능 분리
3. **Phase 3: 세부 설계** -- 항목별 선택지 제시 및 결정
4. **Phase 4: 설계서 정리** -- 구조화된 문서로 정리 및 최종 검토
5. **Phase 5: 전환** -- 설계 확정 후 구현 시작 여부 확인

설계가 100% 확정될 때까지 코드를 작성하지 않습니다.
